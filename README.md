# 💈 Barbearia Black & Red

Landing page institucional desenvolvida para a **Barbearia Black & Red**, com o objetivo de apresentar o estabelecimento, divulgar seus serviços e proporcionar aos clientes uma experiência visual moderna e intuitiva.

O projeto utiliza HTML, CSS e JavaScript, explorando conceitos de desenvolvimento front-end, estilização de interfaces e interatividade.

## 🖥️ Sobre o projeto

A página foi construída com uma identidade visual baseada nas cores preto, vermelho e cinza, buscando transmitir modernidade, personalidade e elegância.

A interface reúne informações sobre a barbearia, apresenta trabalhos realizados, exibe os principais serviços e disponibiliza uma seção de contato com localização integrada ao Google Maps.

## ✨ Funcionalidades

- **Página inicial:** apresentação visual da barbearia.
- **Sobre nós:** seção institucional com descrição do estabelecimento.
- **Galeria de trabalhos:** exposição de exemplos de cortes e resultados.
- **Catálogo de serviços:** apresentação dos serviços oferecidos e seus respectivos preços.
- **Carrossel de serviços:** navegação entre os cards utilizando botões de avançar e retornar.
- **Localização:** mapa integrado ao Google Maps.
- **Contato:** formulário visual para preenchimento de informações.
- **Rodapé:** apresentação institucional e atalhos de navegação.

## 🛠️ Tecnologias utilizadas

| Tecnologia | Aplicação |
|---|---|
| HTML5 | Estruturação da página |
| CSS3 | Estilização e identidade visual |
| JavaScript | Interatividade e navegação do carrossel |
| Ionicons | Ícones da interface |
| Google Maps | Exibição da localização |
| Google Fonts | Tipografia personalizada |
